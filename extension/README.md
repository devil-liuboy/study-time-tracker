# 学习时长统计系统 · 浏览器扩展

适用于 Chrome 和 Microsoft Edge 120 及以上版本，与本机桌面程序配对使用。扩展只提供当前前台网页的域名；最终计时仍由桌面程序的前台进程、网站白名单、锁屏与三分钟空闲回扣规则共同决定。

## 安装与配对

1. 启动学习时长统计系统桌面程序。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本 `extension` 文件夹。
4. 在桌面程序的浏览器设置中复制配对码，点击本扩展图标，粘贴后选择“保存并连接”。界面应显示“已连接本机”。
5. 如同时使用 Chrome 和 Edge，请分别安装、配对。无需刷新已有标签页；扩展不向网页注入脚本。静止阅读网页或在线 PDF 时仍持续上报，桌面程序独立判断键鼠空闲。

开发者模式扩展由本地目录加载，请保留该目录。浏览器可能提示确认此扩展或提供关闭开发者扩展的选项；禁用或移除扩展会停止网页计时。没有发布到扩展商店，也不自动打开开发者模式。

## 数据与权限

- 仅向固定地址 `http://127.0.0.1:47831/v1/activity` 发送数据，不支持远程地址；拒绝重定向。
- 使用桌面程序生成的配对码认证。配对码保存在 `chrome.storage.local`，不使用账号同步。
- 上报当前域名、浏览器类别、窗口焦点、窗口编号、窗口边界及无痕标记。**不发送完整网址、网页标题、正文、按键、点击内容或历史记录。**
- 当前域名与连接状态仅留在扩展会话内存，覆盖更新，不建立浏览日志。桌面程序只应持久化白名单中的统计项目。
- `tabs` 用于确认当前活动标签页并从 URL 提取域名；`storage` 保存配对码与内存状态；`alarms` 用于浏览器事件之外的低频恢复检查。
- 不注册内容脚本，不访问网页 DOM，不监听键盘或鼠标输入，也不请求所有网站的主机权限。通过浏览器扩展 API 查询前台普通窗口及其当前标签页。
- 页面地址栏获得焦点时，只要该浏览器窗口仍处于系统前台，当前显示网页仍可计时。无需网页正文自身获得输入焦点。
- 无痕模式不支持。新标签页、设置页、`file://` 本地文件页等非 HTTP(S) 页面不计入。在浏览器内置 PDF 查看器中打开、标签页 URL 仍为 HTTP(S) 的在线 PDF 可按其域名报告。
- 只看域名无法识别白名单网页内嵌的视频，也无法判断 AI 对话是否用于学习。

## 协议

扩展发送 `POST /v1/activity`，请求头含 `Authorization: Bearer <配对码>` 与 `Content-Type: application/json`。字段如下：

```json
{
  "domain": "arxiv.org",
  "browser": "chrome",
  "focused": true,
  "window_id": 123,
  "incognito": false,
  "window_bounds": {"left": 0, "top": 0, "width": 1280, "height": 800}
}
```

`domain` 为小写主机名或 `null`，没有路径、查询参数或片段。`window_bounds` 可为 `null`，其单位为 Chromium 设备无关像素（DIP），不能直接与 Windows 物理像素比较。无活动窗口时 `focused=false`、`domain=null`。接收端必须再次验证认证信息、原生前台进程、网站白名单和心跳新鲜度；不应仅凭扩展上报认定学习时间。

存在已配对、获得焦点的 HTTP(S) 页面时，每约 2 秒查询浏览器 API 并报告一次。Chrome 110 起，调用扩展 API 会重置服务工作线程的空闲计时器，因此查询可维持工作线程运行；本扩展要求 120 及以上版本，以支持 30 秒的 alarm 恢复检查。窗口焦点、活动标签页及导航变化也会主动更新。浏览器失去焦点或页面不适用时停止高频轮询。

系统休眠、浏览器进程暂停或工作线程异常终止时，扩展不能保证持续报告；桌面端应在心跳超过 5 秒后保守停止网页计时。浏览器恢复后由事件或下一次 alarm 重启轮询，可能有最多约 30 秒的恢复等待，浏览器自身进一步延迟 alarm 时可能更长。不会补记该空窗期。

## 自动检查

有 Node.js 时在此目录运行 `npm test`。测试覆盖 URL 数据最小化、窗口焦点、隐私模式、消息来源与配对码校验；它们不等同于浏览器加载、Windows 前台匹配或完整计时系统的人工验证。
